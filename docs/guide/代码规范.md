# 代码规范（金鳞·点石）

开发 / 构建期由 **ESLint + @stylistic** 强制校验（见根目录 `eslint.config.mjs`）。
`npm run build` 会先执行 `eslint .`，有 error 级问题则中断构建；开发期由 `@nuxt/eslint` 模块在终端 / 浏览器overlay 实时提示。

## 校验命令

```bash
npm run lint        # 仅校验，输出问题
npm run lint:fix    # 自动修复可修复项（缩进、分号、空行、逗号、属性顺序等）
npm run build       # 先 lint 再构建，lint 有 error 则失败
```

## 规则清单

### 错误级（error，阻断构建）

| 规则 | 说明 |
|------|------|
| `@typescript-eslint/no-unused-vars` | 未使用的变量 / 导入报错（下划线前缀 `_` 可豁免，如 `_err`） |
| `no-undef` | 未定义的变量 / 引用报错（Nuxt 自动导入的 `useState`/`useFetch`/`navigateTo` 等由 `@nuxt/eslint` 注入 globals，不会误报） |
| `@stylistic/semi` | 代码里**不要分号** |
| `@stylistic/indent` | **两空格缩进**（模板同样适用 `vue/html-indent`） |
| `@stylistic/eol-last` | 每个文件**最后一行留一行空行** |
| `@stylistic/no-multiple-empty-lines` | **空行最多一个**；文件首尾不允许空行 |
| `@stylistic/comma-dangle` | 对象 / 数组**最后一个元素不加逗号** |
| `@stylistic/arrow-parens` | 箭头函数参数始终带圆括号 |
| `vue/html-self-closing` | HTML 标签必须正确闭合（void 元素自闭合，普通 / 组件元素成对非自闭合） |
| `vue/attributes-order` | Vue 属性书写顺序（采用官方默认顺序） |
| `vue/attribute-hyphenation` | 模板属性使用 **kebab-case**（连字符） |
| `vue/v-on-event-hyphenation` | 模板事件使用 kebab-case |

### 告警级（warning，不阻断构建）

| 规则 | 说明 |
|------|------|
| `@typescript-eslint/no-explicit-any` | `any` 仅告警。本次规范未强制禁止，避免大范围改写既有 `catch (e: any)` 分支；新代码建议用 `unknown` + 类型守卫 |

## 约定

- 优先使用 Nuxt 自动导入的 composables（`useState`、`useFetch`、`navigateTo` 等），无需手动 import。
- 前后端共用常量 / 类型放在 `shared/`（通过 `#shared` 别名引用），避免字符串写岔。
- 图标统一使用 FontAwesome 6：`class="i-fa6-solid:xxx"`（solid）、`i-fa6-regular:xxx`、`i-fa6-brands:xxx`。
- 提交前建议先跑 `npm run lint:fix` 自动格式化，再 `npm run typecheck` 确认类型。
